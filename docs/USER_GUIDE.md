# Guia de uso

## Primeiro acesso

1. Abra o app.
2. Toque em `Ainda não tenho conta`.
3. Preencha nome, e-mail e senha.
4. Volte para `Entrar`.

## Cotações e favoritos

1. Use a busca para localizar uma moeda.
2. Toque na estrela para favoritar.
3. Abra `Favoritos`.
4. Para remover, toque em `Excluir`.
5. Confirme no modal vermelho.

## Carteira

1. Abra `Carteira`.
2. Escolha Bitcoin ou Ethereum.
3. Digite o valor em reais.
4. Toque em `Confirmar compra`.
5. Confira o saldo e o histórico.

## Perfil

1. Abra `Perfil`.
2. Edite nome, sobrenome, e-mail, telefone, data e endereço.
3. Telefone recebe máscara `(11) 99999-9999`.
4. Data recebe máscara `DD/MM/AAAA`.
5. Informe um CPF válido uma única vez.
6. Depois da confirmação, o CPF aparece mascarado e não pode ser editado.
